BUILT FOR CLUB IT & REAL-WORLD RELIABILITY

7 Defense-in-Depth Security Upgrades (Tuned for FCGC)

S1 · Club Embed

Fox Chapel Iframe-Safe Headers

Strict CSP, HSTS, Referrer-Policy, and Permissions-Policy—allowing public pages to embed exclusively on foxchapelgolfclub.org while keeping /manage strictly DENY.

S2 · Edge Guard

Fetch Metadata API Isolation

Blocks cross-site requests to admin APIs before handlers run, while cleanly supporting Club-embedded student submissions and Microsoft Entra OAuth callbacks.

S3 · Crypto

HKDF-SHA256 Key Separation

Derives dedicated subkeys for encrypted mailbox tokens, OAuth state, admin sessions, submission tokens, and rate limits—with seamless v1 read compatibility.

S4 · Club Wi-Fi

Single-Use Nonces & Smart Quotas

Prevents token replay while letting caddies/staff share Club Wi-Fi cleanly: 25/day per IP, 3/day per email, and 80/day global circuit breaker.

S5 · FAFSA Safe

Active-Content PDF & Photo Scanner

Blocks executable PDF JavaScript, Launch, AA, and RichMedia payloads while allowing harmless FAFSA zoom hints, plus JPEG/PNG magic-byte validation on applicant photos.

S6 · OAuth

Hardened Entra OAuth & Diagnostics

Uses __Secure- cookies, constant-time checks, and plain-English alerts if the Entra client secret (expected ~Nov 1, 2027) needs rotation.

S7 · Least Data

Minimized Public Config API

Strips internal edit metadata and secondary review emails from anonymous /api/content responses—shown only to signed-in editors.
