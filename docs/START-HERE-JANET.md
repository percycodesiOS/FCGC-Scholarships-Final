# Janet, start here

This website gives families one place to read the scholarship information and complete the application. Routine wording changes should not require a code editor.

**Scholarship website:** Use the Manage scholarship link on the website; the published link is in the completion receipt.  
**Your editing page:** Use the Manage scholarship link on the website; the published link is in the completion receipt. — `/manage`  
**Application:** Use the Manage scholarship link on the website; the published link is in the completion receipt. — `/apply`

**Setup note:** Your editing email still needs to be confirmed and granted access. Final access and save checks are recorded in `HANDOFF.md`; this guide by itself is not confirmation that those checks have passed. Opening the public website does not give someone editing permission.

## Make a small update

Once your editing access is confirmed:

1. Open your editing page and sign in with the email approved for you. Please use your own account rather than sharing a password.
2. Find the wording you want to change. You can update the public page's introduction, requirements, contact information, and deadline wording.
3. Choose **Preview** and read the change as a visitor would see it.
4. Choose **Save to website** when it is ready. Preview alone does not publish a change.
5. Open the public website again, refresh it, and check that the right wording appears. If saving reports an error, keep the page open and do not assume the change is live.

## Before changing the application year

The current form and documents are for **2027**. Changing the year or deadline on the main page does **not** change the application form or any PDF.

For a new year, have the Foundation approve the new information first. Then arrange for the application form, cover letter, and downloadable PDFs to be updated together. Before announcing the new cycle, check the website and download a sample completed packet using made-up test information.

For the current cycle, the reviewed deadline is **Friday, June 18, 2027, at 4:30 p.m. Eastern Daylight Time**. The online format is still labeled as a review preview pending Foundation approval unless a later approval is recorded.

## What happens to applications?

The application works on the applicant's device. Applicants can save a draft and download their completed PDF. **Downloading does not submit an application.** They must follow the packet's signature and delivery instructions. This website is not an application inbox, and the editing page does not show applicant answers.

## Keep a backup and a successor

- Use **Backup** in the editor to download the current website content as a JSON file. Save it in the Club's shared records after important changes; you do not need to open or edit it.
- Keep the downloadable **website source ZIP** with that backup and the approved application documents. It includes the code, logo, templates, and a standalone website copy for another host.
- Choose a backup staff member. Have their individual editing access tested before they take over, and give them this guide plus `HANDOFF.md`.

These files make it possible to move the site. They do not guarantee that hosting continues after an account, subscription, or service is canceled. Check hosting and account ownership before canceling anything.

If you get stuck, leave the current website in place and give the next maintainer `HANDOFF.md` and your latest backups. They should not need to reconstruct the project from a chat history.
